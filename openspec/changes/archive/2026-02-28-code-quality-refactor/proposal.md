# 代码质量重构提案

## 背景

代码审查发现 6 个重要代码质量问题，涉及全局状态、类级静态变量、函数过长、重复代码等问题。本次重构旨在修复这些问题，同时保持向后兼容性。

## 目标

1. **消除全局状态** - config.py 模块级配置延迟初始化
2. **提取 HTTP 连接池管理** - 避免类级静态变量竞争
3. **拆分长函数** - process_novel 提取执行管道模式
4. **统一错误处理** - 创建 @with_retry 装饰器
5. **消除重复代码** - web_api.py 进度和日志逻辑统一
6. **修复导入问题** - 清理重复导入

## 范围

### 包含
- config.py - 延迟初始化配置
- llm_service.py - 连接池管理器提取
- novel_processing_service.py - 执行管道重构
- web_api.py - 重复代码提取
- utils.py - 导入清理

### 不包含
- 功能变更
- API 接口变更
- 配置项变更

## 向后兼容性

所有现有全局常量保持可用，通过延迟初始化机制确保：
- `config.API_KEY` 等常量继续工作
- `from config import OUTPUT_DIR` 保持兼容
- 现有环境变量配置方式不变

## 风险与缓解

| 风险 | 影响 | 缓解措施 |
|------|------|----------|
| 配置初始化时序变化 | 中 | 保持原有调用链，仅延迟执行 |
| HTTP 客户端生命周期变化 | 中 | 确保关闭逻辑等效 |
| 重构引入新 Bug | 低 | 保持现有测试通过 |

## 成功标准

1. 所有现有测试通过
2. Ruff/Black/Mypy 检查通过
3. 代码审查工具不再报告原有问题
